HOW TO APPLY
------------
1. Unzip this alongside (or over) your existing repo checkout.
2. Copy everything except node_modules/.git/.next into your project
   (those are excluded from this zip already).
3. Run: npm install
4. Run: npm run build   (this will succeed on Vercel/any machine with
   internet access to fonts.googleapis.com — it was only blocked in my
   sandboxed environment, which has an allowlist that doesn't include
   Google Fonts)
5. Run: npm run lint && npm run typecheck   (both pass clean)
6. Commit and push — Vercel will redeploy automatically if connected.
